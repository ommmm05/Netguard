1.1 Abstract

NetGuard is an AI-driven cybersecurity research prototype that provides passive network monitoring, machine-learning-based threat detection, and forensic incident intelligence through a unified SOC-style dashboard. The system captures live network traffic via TShark/Scapy, reconstructs bidirectional 5-tuple flows, extracts 20-dimensional CICIDS2017-aligned feature vectors, and classifies threats using a Random Forest + XGBoost + Isolation Forest ensemble. Forensic analysis is powered by SHAP explainability, MITRE ATT&CK mapping, incident correlation, and LLM-assisted report generation. The platform is built with FastAPI (Python) and React + Vite + Tailwind CSS (TypeScript), persisting all state in SQLite.

1.2 Introduction

Modern network environments face increasingly sophisticated cyber threats including DoS attacks, port scans, brute-force intrusions, and anomalous exfiltration patterns. Traditional signature-based IDS tools often fail against zero-day and polymorphic threats. NetGuard addresses this gap by combining passive packet capture with ensemble machine learning and forensic intelligence in a three-phase modular architecture, enabling security analysts to monitor, detect, and investigate network threats from a single unified interface.

1.3 Problem Statement

Existing network security tools rely heavily on signature-based detection, lack real-time ML-driven threat classification, and do not provide integrated forensic investigation capabilities. There is a need for a unified platform that passively monitors network traffic, automatically classifies threats using ML, and provides explainable forensic intelligence with actionable remediation guidance — all without active scanning or packet injection.

1.4 Objectives
  • Implement passive network capture via TShark and Scapy (no active scanning or injection).
  • Reconstruct bidirectional 5-tuple flows and extract 20-dim CICIDS2017 feature vectors.
  • Train and deploy a 3-model ML ensemble (Random Forest, XGBoost, Isolation Forest) for threat classification.
  • Provide SHAP-based explainability and MITRE ATT&CK mapping for forensic analysis.
  • Build a real-time SOC dashboard with React for unified monitoring and investigation.
  • Support PCAP upload, live capture, and offline replay modes.

1.12 Conclusion

NetGuard successfully demonstrates an end-to-end AI-driven network security platform that integrates passive packet capture, ML-based threat detection, and forensic incident intelligence into a unified SOC dashboard. The three-phase modular architecture (Visibility → Detection → Forensics) enables complete network threat lifecycle management. The platform's passive-only design, SHAP explainability, MITRE ATT&CK mapping, and LLM-assisted reporting make it a practical research prototype for academic and small-scale SOC environments.

1.9 Algorithms

NetGuard uses a 3-model ensemble trained on CICIDS2017-aligned features. Classification: Benign, DoS, PortScan, BruteForce. Anomaly detection via Isolation Forest sigmoid scoring.

AlgorithmInputProcessingOutput
Random Forest 20-dim feature vector 200 trees, max depth 20, balanced class weights Class probabilities + prediction
XGBoost 20-dim feature vector 200 estimators, depth 6, lr=0.1, mlogloss Class probabilities + prediction
Isolation Forest 20-dim feature vector 200 estimators, contamination=0.1, sigmoid transform Anomaly score (0–1)
Ensemble Decision RF + XGB probabilities, IF score Average confidence; majority vote; IF anomaly threshold >0.6 Alert (type, severity, confidence)
SHAP TreeExplainer Alert feature vector + RF model Shapley value computation for each feature Top-12 feature contributions (waterfall)
Heuristic Detector Flow metadata (ports, bytes, duration) Pattern matching: C2 ports, RDP external, SMB, port scan Threat label + severity flag

Feature Vector (20-dim): dst_port, src_port, flow_duration, tot_fwd_pkts, tot_bwd_pkts, totlen_fwd/bwd_pkts, fwd/bwd_pkt_len (max, min, mean), flow_byts/pkts_s, pkt_len (mean, std), syn/ack_flag_count, down_up_ratio.

1.10 Results
  • Three-phase pipeline (Visibility → Detection → Forensics) implemented end-to-end with full API coverage (30+ REST endpoints).
  • ML ensemble (RF + XGBoost + IsoForest) trained on CICIDS2017 dataset with real evaluation metrics (accuracy, precision, recall, F1) computed via stratified 80/20 train-test split.
  • Live capture via TShark subprocess with real-time SSE packet streaming and bidirectional flow tracking (5-tuple, 20-dim CICIDS feature extraction).
  • SHAP TreeExplainer successfully generates per-alert feature contribution waterfall charts.
  • MITRE ATT&CK mapping covers DoS (T1498/T1499), PortScan (T1046/T1018), BruteForce (T1110/T1078), and Anomaly (T1071/T1048).
  • Forensic PDF reports generated via ReportLab with alert details, SHAP, timeline, and remediation steps.
  • Pytest test suite validates: flow key bidirectionality, TShark EK JSON parsing, flow tracker aggregation, 20-dim vector alignment, detection ensemble adapter, capture manager lifecycle, API endpoint shapes, and bearer token auth.
1.11 Discussion

Passive-Only Design: NetGuard does not scan, inject, spoof, MITM, or decrypt TLS — ensuring legal and ethical compliance while maintaining visibility through metadata analysis (SNI, DNS, ARP, HTTP Host headers).

Ensemble Advantage: Combining supervised classifiers (RF, XGBoost) with an unsupervised anomaly detector (Isolation Forest) provides robust detection: supervised models handle known attack categories while IF catches novel anomalies not represented in training data.

Explainable AI: SHAP TreeExplainer grounds each alert in specific flow features (e.g., flow_byts_s, syn_flag_count), enabling analysts to verify whether a detection is based on meaningful traffic characteristics rather than artifacts.

Modular Architecture: Each phase (capture, visibility, detection, forensics) is a self-contained Python package with clean imports, enabling independent development, testing, and extension.
